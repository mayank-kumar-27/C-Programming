# 07-Strings

## Theory
Strings in C are arrays of characters terminated by a null character ('\0'). This folder covers string manipulation, character operations, and common string algorithms. Key concepts include:
- String declaration and initialization
- String input/output functions (gets, puts, scanf, printf)
- String library functions (strlen, strcpy, strcmp, strcat, etc.)
- Manual string operations without library functions
- Character classification and conversion
- String searching and manipulation
- Pattern matching and anagram checking
- String sorting and reversal

## Objective
The objective is to understand string handling in C, learning both built-in functions and manual implementations for string operations.
