# 10-Dynamic-Memory-Allocation

## Theory
Dynamic memory allocation allows programs to allocate memory at runtime. This folder covers malloc, calloc, realloc, and free functions, along with memory management best practices. Key concepts include:
- Static vs dynamic memory allocation
- malloc(): allocate memory block
- calloc(): allocate and initialize memory
- realloc(): resize allocated memory
- free(): deallocate memory
- Memory leaks and dangling pointers
- Heap vs stack memory
- Dynamic arrays and data structures
- Error handling for allocation failures
- Memory management in complex data structures

## Objective
The objective is to understand dynamic memory management, learning to allocate and deallocate memory efficiently while avoiding common pitfalls like memory leaks.
