# Functions

## Theory
Functions in C are blocks of code that perform specific tasks. This folder explores function definition, declaration, calling, and various types of functions. Key concepts include:
- Function declaration and definition
- Function parameters and arguments
- Return types and values
- Call by value vs call by reference
- Recursion: functions calling themselves
- Scope and lifetime of variables
- Function prototypes
- Passing arrays and strings to functions
- Returning multiple values

## Objective
The objective is to understand modular programming through functions, learning how to break down programs into reusable, maintainable components.
