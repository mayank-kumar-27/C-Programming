# 04-Loops

## Theory
Loops in C allow repetitive execution of code blocks. This folder covers for, while, and do-while loops, along with loop control statements. Key concepts include:
- For loop: Entry-controlled loop with initialization, condition, and increment
- While loop: Entry-controlled loop based on condition
- Do-while loop: Exit-controlled loop that executes at least once
- Nested loops for complex patterns
- Break and continue statements for loop control
- Infinite loops and their prevention
- Loop optimization techniques

## Objective
The objective is to understand and implement various looping constructs in C, learning to solve problems that require repetition and iteration.
