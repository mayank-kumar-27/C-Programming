# 01-Basics

## Theory
This folder covers the fundamental concepts of C programming, including data types, variables, constants, and basic input/output operations. Understanding these basics is essential as they form the building blocks for all C programs. Key concepts include:
- Data types (int, float, char, double)
- Variables and their declaration
- Constants and literals
- Basic I/O functions (printf, scanf)
- Comments and program structure

## Objective
The objective of this folder is to provide a solid foundation in C programming basics, enabling learners to write simple programs that can read input, perform basic calculations, and display output.
