# 11-File-Handling

## Theory
File handling in C involves reading from and writing to files on disk. This folder covers file operations, different file modes, and both text and binary file processing. Key concepts include:
- File pointers and file streams
- File opening modes (r, w, a, r+, w+, a+)
- Text file operations (fprintf, fscanf, fgets, fputs)
- Character-based I/O (fgetc, fputc)
- Binary file operations (fread, fwrite)
- File positioning (fseek, ftell, rewind)
- Error handling in file operations
- Random access files
- Working with structured data in files
- Command-line file operations

## Objective
The objective is to master file I/O operations in C, learning to persist data and handle external file resources efficiently and safely.
