# 09-Structures-and-Unions

## Theory
Structures and unions are user-defined data types that group related variables. This folder covers creating custom data types, memory management, and advanced features like bit fields. Key concepts include:
- Structure definition and declaration
- Accessing structure members
- Nested structures
- Arrays of structures
- Pointers to structures
- Structures as function parameters and return types
- Typedef for type aliases
- Memory alignment and padding
- Unions for memory-efficient storage
- Enumerations for named constants
- Bit fields for compact data storage
- Self-referential structures for linked data structures

## Objective
The objective is to learn creating and manipulating complex data types, understanding memory layout, and implementing data structures for real-world applications.
