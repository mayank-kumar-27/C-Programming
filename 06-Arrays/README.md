# 06-Arrays

## Theory
Arrays in C are collections of similar data items stored in contiguous memory locations. This folder covers one-dimensional and two-dimensional arrays, along with common operations and algorithms. Key concepts include:
- Array declaration, initialization, and access
- One-dimensional vs multi-dimensional arrays
- Array operations: traversal, insertion, deletion, searching
- Sorting algorithms: bubble, selection, insertion, quick, merge
- Searching algorithms: linear and binary search
- Array manipulation: rotation, reversal, merging
- Memory allocation for arrays
- Passing arrays to functions

## Objective
The objective is to master array manipulation and understand fundamental algorithms for sorting and searching, building a foundation for data structure concepts.
