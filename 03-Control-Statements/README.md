# Control Statements

## Theory
Control statements in C allow programs to make decisions and repeat actions. This folder covers conditional statements (if-else, switch) and iterative statements (loops). Key concepts include:
- Conditional statements: if, if-else, nested if, else-if ladder
- Switch-case statements for multi-way branching
- Loop control: for, while, do-while loops
- Break and continue statements
- Nested loops and control structures
- Decision-making based on conditions

## Objective
The objective is to master control flow in C programs, learning how to implement decision-making and repetition logic effectively.
